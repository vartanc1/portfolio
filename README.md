# Vartan Chakryan Portfolio

Single-page portfolio site in plain HTML, CSS, and JavaScript. No build step.

## Files
- `index.html`: the whole site (styles and scripts included)
- `images/uav-1.jpg`: aircraft photo (slide 1)
- `images/uav2-vid.mov`: aircraft video (slide 2), add your file here. An H.264 `uav2-vid.mp4` also works and plays in more browsers.
- `images/robot.jpg`: robot photo

Also add `resume.pdf` next to `index.html` for the Résumé link.

## Run locally
Open `index.html` in a browser.

## Host on GitHub Pages
1. Create a repo named `YOUR-USERNAME.github.io`.
2. Upload these files to the repo root.
3. Settings → Pages → Deploy from branch → `main` / root.
4. Your site goes live at `https://YOUR-USERNAME.github.io`.
